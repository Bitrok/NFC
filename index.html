Configurar API key

La clave se guarda únicamente en este navegador (localStorage) y nunca se envía a ningún servidor que no sea Google.

La clave está definida en js/config.js, así que no se puede cambiar desde aquí. Edita ese archivo para modificarla.

Necesita Maps JavaScript API y Places API (New) habilitadas, y la clave restringida por referente HTTP. Instrucciones en el README.
